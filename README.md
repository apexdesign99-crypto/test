# 音声会話

ブラウザのマイクに話しかけると、Claude が音声で返してくれる Web アプリです。
音声認識と読み上げはブラウザの Web Speech API、返答の生成は Claude API（`claude-opus-5`）を使います。

```
ブラウザ（音声認識） → Node サーバー → Claude API
ブラウザ（読み上げ） ←  SSE で逐次  ←
```

返答は文が出来上がったそばから読み上げるので、生成が終わるのを待たずに話し始めます。

## 必要なもの

- Node.js 20 以降
- Claude API キー（<https://console.anthropic.com/> で発行）
- Chrome / Edge / Safari のいずれか（音声認識に対応しているブラウザ）

## セットアップ

```bash
npm install
cp .env.example .env      # ANTHROPIC_API_KEY を書き込む
npm run build
npm start
```

<http://127.0.0.1:3000> を開き、マイクの使用を許可してから「話す」を押します。

`ant auth login` でログイン済みのプロファイルがあれば `ANTHROPIC_API_KEY` は省略できます（SDK が自動で読みます）。

開発中は `npm run dev` で TypeScript の監視ビルドとサーバーの再起動が走ります。

## 使い方

| 操作 | 内容 |
| --- | --- |
| 「話す」ボタン / スペースキー | 録音の開始・停止。話し終えて数秒黙ると自動で送信されます |
| 読み上げ中に「話す」 | 読み上げを止めてすぐ聞き取りに入ります（割り込み） |
| ハンズフリー | 返答の読み上げが終わると自動でマイクが開き、そのまま会話が続きます |
| テキスト入力欄 | 声を出せない場所や、音声認識が使えないブラウザ用 |
| 会話をリセット | 履歴を捨てて最初から話し直します |

設定（言語・声・速度・ハンズフリー・読み上げの有無）はブラウザに保存されます。
言語を English に切り替えると、認識・読み上げ・Claude への指示がまとめて英語になります。

## 環境変数

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | （必須） | Claude API キー |
| `HOST` | `127.0.0.1` | 待ち受けアドレス |
| `PORT` | `3000` | 待ち受けポート |
| `VOICE_MODEL` | `claude-opus-5` | 使用するモデル |
| `VOICE_EFFORT` | `low` | 思考の深さ（`low`〜`max`）。会話のテンポを優先して既定は `low`、じっくり考えさせたいときは `high` など |
| `VOICE_MAX_TOKENS` | `4096` | 返答の最大トークン数 |
| `MAX_HISTORY_MESSAGES` | `40` | 1 リクエストで受け付ける履歴の件数 |
| `MAX_MESSAGE_CHARS` | `4000` | 1 発話あたりの文字数上限 |

## 構成

| ファイル | 役割 |
| --- | --- |
| `src/server.ts` | Hono 製。静的ファイル配信と `POST /api/chat`（SSE で返答を流す） |
| `src/claude.ts` | Claude API 呼び出しと、読み上げ向けのシステムプロンプト |
| `src/config.ts` | 環境変数の読み取り |
| `public/app.js` | 音声認識 → 送信 → 読み上げのループ |
| `public/index.html`, `public/styles.css` | 画面 |

API キーはサーバー側だけが持ち、ブラウザには渡りません。会話履歴はブラウザのメモリ上にだけ置かれ、
毎回のリクエストで直近 40 件までがサーバーへ送られます（サーバーは保存しません）。

Claude の返答が安全上の理由で拒否された場合は、同じ呼び出しの中でサーバー側の既定のフォールバックモデルが
引き継ぎます（`fallbacks: "default"`）。この指定が受け付けられない環境では、自動的に外して再試行します。

## 制限・注意

- 音声認識は Web Speech API に依存します。Firefox は未対応で、テキスト入力のみ使えます。
  Chrome の音声認識は音声データを Google のサーバーへ送って処理します。
- マイクは `https://` か `localhost`（`127.0.0.1`）でしか使えません。
  他の端末から使う場合は TLS 終端を挟むか、ポートフォワードしてください。
- ハンズフリー中はスピーカーの音をマイクが拾うことがあります。イヤホンの使用をおすすめします。
- 読み上げの声は OS にインストールされているものだけが選べます。日本語の声が無い環境では英語の声で読まれます。
- 画面まわりの日本語表記（ボタンやラベル）は言語切り替えの対象外です。
