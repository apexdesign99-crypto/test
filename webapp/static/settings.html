取り扱いの注意

  • API キーはサーバ上の設定ファイルに保存され、所有者だけが読み書きできる権限（0600）になります。保存先は上の「現在の状態」に表示されます。
  • 画面・API がキーを返すことはありません（末尾4文字以外はマスクされます）。
  • 設定ファイルは .gitignore 済みです。リポジトリにコミットしないでください。
  • このアプリに認証機能はありません。設定画面を含め、外部に公開せず、ローカルまたは社内ネットワーク限定で使ってください。
  • キーが漏れた恐れがある場合は、提供元で再発行し、この画面で登録し直してください。

設定は環境変数でも指定できます（AI_LAND_DESIGN_LIVE / REINFOLIB_API_KEY / AI_LAND_DESIGN_ZONING_GEOJSON ほか）。この画面の保存値が環境変数より優先されます。
