# 大丸開発株式会社 コーポレートサイト

建築・土木・不動産開発を手がける総合建設会社を想定した、コーポレートサイトの静的実装です。
ビルドツールや外部ライブラリに依存しないため、ファイルをそのまま静的ホスティング
（GitHub Pages、Netlify、レンタルサーバー等）へ配置すれば公開できます。

## ページ構成

| ファイル | ページ | 主な内容 |
| --- | --- | --- |
| `index.html` | ホーム | ヒーロー、事業内容、選ばれる理由、施工実績抜粋、問い合わせ導線 |
| `about.html` | 会社概要 | 代表挨拶、会社概要表、沿革、アクセス |
| `business.html` | 事業内容 | 建築 / 土木 / 不動産開発の各事業、お問い合わせから完成までの流れ |
| `works.html` | 施工実績 | 分野別の実績一覧 |
| `recruit.html` | 採用情報 | 募集職種、募集要項、応募の流れ |
| `contact.html` | お問い合わせ | 問い合わせフォーム（クライアントサイド検証付き） |
| `park-toki/index.html` | 大丸パーク土岐 LP | 総合住宅展示場の来場予約用ランディングページ（独立デザイン） |

## ローカルでの確認

ファイルを直接ブラウザで開いても閲覧できますが、簡易サーバー経由を推奨します。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## 実装方針

- **依存なし** — フレームワーク、CSS ライブラリ、外部フォント、外部画像を使用していません。
  ロゴやアイコンはインライン SVG、実績のサムネイル枠は CSS グラデーションで表現しています。
- **レスポンシブ** — 1024px 未満でハンバーガーメニューに切り替わります。
  デスクトップ（1280px）とモバイル（390px）で横スクロールが発生しないことを確認済みです。
- **アクセシビリティ** — 本文へのスキップリンク、`aria-current` による現在地表示、
  ハンバーガーの `aria-expanded`、フォームのラベルとエラーの `role="alert"`、
  フォーカスリング、`prefers-reduced-motion` への対応を入れています。
- **印刷** — ヘッダー・フッター・CTA を非表示にする印刷用スタイルを含みます。

## 公開前に差し替えが必要な箇所

サイト内の以下の項目は**すべて記入例（プレースホルダ）**です。実在の情報に置き換えてください。
`○` を含む文字列を検索すると該当箇所を一括で確認できます。

```sh
grep -rn "○\|000-000-0000\|000-0000\|tel:0000000000\|example.com" --include="*.html" --include="*.xml" .
```

| 箇所 | 内容 |
| --- | --- |
| 全ページのフッター | 住所、電話番号、FAX、営業時間 |
| `about.html` | 代表者名、設立、資本金、従業員数、所在地、**建設業許可番号、宅建業免許番号**、取引銀行、沿革、アクセス |
| `works.html` | 工事名、規模、竣工年（掲載には発注者の同意が必要です） |
| `recruit.html` | 給与、休日、諸手当などの労働条件（労働条件通知書との一致を必ず確認してください） |
| `contact.html` | 電話番号、フォームの送信先 |
| `park-toki/index.html` | 所在地、営業時間、定休日、駐車場台数、**出展ハウスメーカー名と棟数**、モデルハウスの仕様、IC からの所要時間、イベントの開催期間と特典、問い合わせ先 |
| `sitemap.xml` / 各ページの OGP | 公開ドメイン（現在は `https://example.com/`） |

許可番号・免許番号・実績・労働条件は、事実と異なる内容を掲載すると法令上の問題になり得るため、
公式な書類の記載内容をそのまま反映してください。

## 大丸パーク土岐 ランディングページ（`park-toki/`）

岐阜県土岐市で開発中の総合住宅展示場「大丸パーク土岐」の、来場予約用ランディングページです。
**2027年1月15日グランドオープン**予定。

来場者（家づくりを検討中のご家族）に向けて、コーポレートサイトとは別デザイン
（暖色のオフホワイト基調＋テラコッタ／グリーン）の1枚もので構成しています。
専用の `park-toki/assets/` を読み込み、コーポレートサイト側の CSS/JS には依存しません。

### セクション構成

ヒーロー（カウントダウン付き）→ 展示場について → 出展モデルハウス → 館内施設 →
グランドオープンイベント → アクセス・営業時間 → よくある質問 → 来場予約フォーム

### カウントダウン

グランドオープンまでの残り日数・時間を表示します。目標日時は HTML の `data-countdown` 属性で
指定しているため、**日付を変える場合は HTML の1箇所を直すだけ**で反映されます。

```html
<div class="countdown" data-countdown="2027-01-15T00:00:00+09:00">
```

値は ISO 8601 形式・タイムゾーン付きで指定してください（`+09:00` は日本時間）。
オープン日を過ぎると自動的にカウントダウンが消え、「グランドオープンしました」表示に切り替わります。

### 出展ハウスメーカーの掲載について

モデルハウスのカードに記載している会社名（`○○ホーム` など）と仕様は**すべて記入例**です。
出展契約が確定した会社名に差し替えてください。
他社の社名・商標を掲載する際は、**必ず各社の許諾を得たうえで、各社の表記ルールに従って**ください。
外観写真が用意できたら、`.house__photo` を `<img>` に置き換えてください。

### イベント・特典の掲載について

グランドオープンイベントの期間、記念品、来場予約特典はいずれも記入例です。
特典や景品を掲載する際は、景品表示法上の上限や「先着○名様」などの条件表記もあわせてご確認ください。

### よくある質問

`<details>` / `<summary>` で実装しているため、JavaScript を使わずに開閉します。
項目の増減は HTML の `.faq__item` を複製・削除するだけで対応できます。

### 立地情報の扱い

「土岐IC（中央自動車道）」「土岐南多治見IC（東海環状自動車道）」「JR中央本線 土岐市駅」は
実在の施設名として記載していますが、**そこからの所要時間はすべて記入例**です。
実測値または経路検索の結果に差し替え、所要時間は交通状況により変動する旨の注記を添えてください。

## お問い合わせフォームについて

`contact.html`（お問い合わせ）と `park-toki/index.html`（来場予約）のフォームは、
現時点では**送信先が未設定**です。
それぞれ `assets/js/main.js` と `park-toki/assets/js/lp.js` が入力内容を検証し、
`action` が空の間は送信せずその旨を表示します。

運用時は次の対応が必要です。

1. `<form>` の `action`（および必要に応じて `method`）に、メール送信スクリプトや
   フォームサービスのエンドポイントを設定する。
2. 送信完了ページを用意する（来場予約フォームは予約完了ページ）。
3. **サーバー側でも入力値を検証する**。クライアントサイドの検証は入力補助であり、
   セキュリティ上の防御にはなりません。
4. スパム対策（reCAPTCHA、hidden フィールド、レート制限など）を実装する。
5. 個人情報の取り扱いについて、プライバシーポリシーページを別途用意する。
