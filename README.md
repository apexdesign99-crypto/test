# 血圧ボイス記録

毎日の血圧を **音声で記録** して、日別・週・月の平均を **自動集計** するブラウザアプリです。
インストール不要・依存パッケージなしで、スマートフォンでも PC でも動きます。

## できること

- 🎙 **音声入力** — 「朝の血圧、上が132、下が84、脈は68」と話すだけで記録
- ✅ **確認してから保存** — 聞き取り結果を編集できる確認カード（自動保存は3秒カウントダウン、その間に修正可）
- 📊 **自動集計** — 今日／7日／30日の平均、朝晩別の平均、月別集計、連続記録日数
- 📈 **推移グラフ** — 日別平均と7日移動平均、家庭血圧の高血圧基準（135/85）の目安線つき
- 🏷 **区分の目安** — 日本高血圧学会 JSH2019 の家庭血圧基準で自動判定
- 💾 **CSV 書き出し／取り込み** — かかりつけ医に渡す・別端末へ移すときに
- 📴 **オフライン対応** — Service Worker でキャッシュ、ホーム画面に追加すればアプリのように使える
- 🔒 **データは端末内のみ** — localStorage に保存し、サーバーへは送信しません

## 使い方

1. `index.html` を **HTTPS（または localhost）** で開く。※音声認識にはセキュアな接続が必要です
2. マイクボタンをタップして話す
3. 表示された数値を確認して「保存する」（自動保存 ON なら3秒後に自動確定）

ローカルで試す場合:

```bash
npm start          # http://localhost:8080 で配信（python3 -m http.server）
```

スマートフォンで毎日使うなら、GitHub Pages などの HTTPS ホスティングに配置し、
ブラウザの「ホーム画面に追加」でアプリとして起動するのが簡単です。

## 話し方の例

| 発話 | 解釈 |
| --- | --- |
| 上が132、下が84、脈は68 | 132 / 84、脈拍 68 |
| 最高血圧145 最低血圧92 脈拍数80 | 145 / 92、脈拍 80 |
| 血圧は130の85 | 130 / 85 |
| 128 82 70 | 132 / 84 のように「大きい方＝最高」と並び順で解釈 |
| 上が百三十、下が八十五 | 漢数字にも対応 |
| 夜の血圧、130の82 | 時間帯＝晩（無指定なら測定時刻から朝／晩を判定） |
| 昨日の夜、上が128、下が80 | 昨日の記録として保存（「一昨日」「8月20日」も可） |

聞き取れなかった値や、ありえない値（最高血圧が最低血圧以下など）は保存せずに言い直しを促します。

## 構成

```
index.html              画面
css/style.css           スタイル（ライト／ダーク対応）
js/parser.js            発話テキスト → 血圧レコードの変換（純関数）
js/stats.js             平均・区分判定・日別／月別集計・移動平均（純関数）
js/storage.js           localStorage 保存と CSV 入出力
js/app.js               音声認識と画面の描画
sw.js / manifest.webmanifest   オフライン・ホーム画面追加用
test/                   node:test によるユニットテスト
```

## テスト

```bash
npm test
```

`parser.js` と `stats.js` は DOM に依存しない純関数なので、ブラウザなしでテストできます。

## 対応ブラウザ

音声入力は Web Speech API を使うため、**Chrome / Edge / Safari** で利用できます。
非対応のブラウザでは自動的に「手入力で記録する」に切り替えて使えます（集計機能はすべて同じように動きます）。

## 注意

表示される区分は日本高血圧学会 JSH2019 の家庭血圧基準に基づく **目安** であり、診断ではありません。
