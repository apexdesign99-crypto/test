# 血圧ボイス記録

毎日の血圧を **音声で記録** して、日別・週・月の平均を **自動集計** するアプリです。
Capacitor を使って **iOS / Android のネイティブアプリ**として動き、同じコードが **PC のブラウザ**でも動きます。

## できること

- 🎙 **音声入力** — 「朝の血圧、上が132、下が84、脈は68」と話すだけで記録
  （アプリ版は端末の音声認識、ブラウザ版は Web Speech API）
- ✅ **確認してから保存** — 聞き取り結果を編集できる確認カード（自動保存は3秒カウントダウン、その間に修正可）
- 📊 **自動集計** — 今日／7日／30日の平均、朝晩別の平均、月別集計、連続記録日数
- 📈 **推移グラフ** — 日別平均と7日移動平均、家庭血圧の高血圧基準（135/85）の目安線つき
- 🏷 **区分の目安** — 日本高血圧学会 JSH2019 の家庭血圧基準で自動判定
- 🔔 **毎日のリマインダー** — 決まった時刻にローカル通知（アプリ版のみ）
- 💾 **CSV 書き出し／取り込み** — アプリ版は共有シート、ブラウザ版はダウンロード
- 🔒 **データは端末内のみ** — Capacitor Preferences に保存し、サーバーへは送信しません

## セットアップ

```bash
npm install       # 依存関係のインストール
npm run build     # src/ → www/js/app.js をバンドル
```

### ブラウザで使う / 開発する

```bash
npm run dev       # ビルドして http://localhost:8080 で配信
npm run watch     # src/ の変更を監視して自動ビルド
```

音声認識にはセキュアな接続が必要なので、`localhost` か HTTPS で開いてください。

### iOS アプリとして動かす（要 Mac + Xcode）

```bash
npm run sync      # www/ をネイティブプロジェクトへ反映
cd ios/App && pod install && cd ../..
npm run ios       # Xcode で開く → 実機／シミュレータへ実行
```

音声認識は**実機**で確認してください（シミュレータでは動作しないことがあります）。
マイクと音声認識の利用目的は `ios/App/App/Info.plist` に記載済みです。

### Android アプリとして動かす（要 Android Studio）

```bash
npm run sync
npm run android   # Android Studio で開く → 実機／エミュレータへ実行
```

`RECORD_AUDIO`・`POST_NOTIFICATIONS` などの権限は `AndroidManifest.xml` に設定済みです。
APK を作る場合は Android Studio の Build > Build Bundle(s) / APK(s) から生成できます。

## 話し方の例

| 発話 | 解釈 |
| --- | --- |
| 上が132、下が84、脈は68 | 132 / 84、脈拍 68 |
| 最高血圧145 最低血圧92 脈拍数80 | 145 / 92、脈拍 80 |
| 血圧は130の85 | 130 / 85 |
| 128 82 70 | 「大きい方＝最高」と並び順で解釈 |
| 上が百三十、下が八十五 | 漢数字にも対応 |
| 夜の血圧、130の82 | 時間帯＝晩（無指定なら測定時刻から朝／晩を判定） |
| 昨日の夜、上が128、下が80 | 昨日の記録として保存（「一昨日」「8月20日」も可） |

聞き取れなかった値や、ありえない値（最高血圧が最低血圧以下など）は保存せずに言い直しを促します。
認識候補が複数ある場合は、血圧として読めた候補を優先して採用します。

## 構成

```
src/parser.js        発話テキスト → 血圧レコードの変換（純関数）
src/stats.js         平均・区分判定・日別／月別集計・移動平均（純関数）
src/storage.js       Preferences への保存と CSV 入出力
src/speech.js        音声認識（ネイティブ／Web Speech API の切り替え）
src/reminder.js      毎日のリマインダー通知
src/export.js        CSV の共有・ダウンロード
src/app.js           画面の組み立て
www/                 配信されるアプリ本体（index.html, css, 生成された js）
android/ ios/        Capacitor が生成したネイティブプロジェクト
resources/           アプリアイコン・スプラッシュの元画像
tools/               ネイティブ分岐をブラウザで確認するためのスタブ
test/                node:test によるユニットテスト
```

## テスト

```bash
npm test              # パーサと集計ロジックのユニットテスト
npm run preview:native # ネイティブのプラグイン呼び出しをスタブして動作確認
```

`parser.js` と `stats.js` は DOM にもプラグインにも依存しない純関数なので、ブラウザなしでテストできます。
`npm run preview:native` は Capacitor のブリッジを模擬したページを配信するので、
実機ビルドをしなくても「アプリ版の分岐」（音声認識・通知・共有）をブラウザで確認できます。

## アイコンを差し替えるには

`resources/icon.png`（1024×1024）と `resources/splash.png` を置き換えて、次を実行します。

```bash
npx capacitor-assets generate
```
